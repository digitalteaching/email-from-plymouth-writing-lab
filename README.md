# Writing Lab: An email from Plymouth

Begleitetes Schreibtraining Englisch Klasse 8 (Unit 2): Aufbau einer E-Mail, Fakten zu Pilgrims, Wampanoag und Thanksgiving, Unit-Wortschatz, Present Perfect Progressive mit for und since, dann eine eigene E-Mail als Austauschschüler in Plymouth Teil für Teil mit Rückmeldung, QR-Abgabe und Game Zone. Eine HTML-Datei, passwortgeschützt.

Link: https://digitalteaching.github.io/email-from-plymouth-writing-lab/
